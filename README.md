# Tres en raya en Python

Proyecto de programación de un juego de tres en raya
con una inteligencia artificial capaz de jugar
mediante el algoritmo Minimax.

## Objetivo

Desarrollar el juego progresivamente, desde la
representación del tablero hasta una IA capaz
de elegir la mejor jugada posible.

## Fases del proyecto

- [x] Fase 1: Representación e impresión del tablero
- [x ] Fase 2: Reglas del juego
- [x ] Fase 3: Juego para dos personas
- [X ] Fase 4: Máquina con movimientos aleatorios
- [X ] Fase 5: Inteligencia artificial con Minimax

## Tecnologías

- Python 3
- Git
- GitHub

## Ejecución

Descarga el repositorio y ejecuta:

```bash
python main.py
```
